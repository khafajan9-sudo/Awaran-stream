# Awaran Stream
A VLC-style Android video player with a gold & white interface, built on Media3 ExoPlayer.

**Features:** local files, network streams (MP4, HLS, DASH), playback speed, seek bar, "Open with" for video files.

## Get the APK
1. Push this repo to GitHub.
2. Open **Actions → Build APK → Run workflow** (it also runs on every push).
3. Download **AwaranStream-apk** from the run's Artifacts, unzip, and install `app-debug.apk`.

## Build locally
Open in Android Studio and press Run, or run `gradle assembleDebug`.
